What is actually verified.

40,223,554Real exchange messages decoded across a full 4.8 GB trading day — zero errors, zero unknown message types, zero sequence gaps.
0Corrupted books across 38,993,905 updates. The exchange splits one logical book change across several messages, so the book is legitimately inconsistent in between; the check is gated on the feed's event-complete flag, which keeps it strict exactly where it means something.
2Independent implementations — a throwaway Python decoder written first, then the Rust — agreeing exactly on every per-type message count.
109 + 158 + 11Rust tests, C++ checks and Python tests, plus the lock-free queue model-checked across every ordering the memory model permits. Development is on ARM64, whose weak memory model breaks lock-free code that x86 would have hidden.
1External dependency (thiserror) across six Rust crates.

Figures from “Try it” are measured live on shared cloud hardware and wobble more than a pinned machine; the counts above come from a full trading day on a pinned one.
